군사 논리 시뮬레이션 (Linux 시험 장치 전용, 게임에 들어가지 않음)

army_sim.inc 를 engine_main.c 사본 끝에 붙여(원래 main 은 이름을 바꿔) 엔진 전체와 함께 링크한 실행 파일로 돌린다.
  army-sim <Caesar III 자료 폴더> <빈 작업 폴더> 2      (2 = 캠페인 지도 번호)
  SIM_DEFEND=1 을 주면 공격받는 도시에 자기 군단이 있는 변형.
한 도시가 모든 역할을 한다: 자기 요새 군단이 실제 우편함(mp_army_poll, 1~4단계)으로 떠나고, 같은 명세가 이 도시에
방문 지원군 / 공격군으로 도착한다(다른 플레이어 도시에 도착하는 것과 같은 코드). 화면·방 서버·두 번째 게임은 없다.
지도 길가에 집 24채와 창고를 놓고, 실제 game_tick_run() 으로 수천 틱을 돌린다. 결과는 PASS/FAIL 줄.
Windows 에서는 돌리지 않았다(Linux 빌드 장치의 shim 과 링크 방법에 의존).
